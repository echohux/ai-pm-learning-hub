# AI PM 知识打卡站 · 使用说明

版本：v11.21（单文件 Web 应用，无需安装、无需启动服务）
发布时间：2026-10-09

## 一、这是什么

面向 AI 产品经理的日常学习打卡工具：每天学习「AI 产品经理」相关知识卡并打卡，支持复习队列、知识库浏览、学习统计与进度云端同步。全部功能封装在一个 HTML 文件中。

## 二、快速开始

1. 直接打开[在线网站](https://echohux.github.io/ai-pm-learning-hub/)（推荐 Chrome / Edge / Safari 最新版）。
2. 首次进入点击「注册」：填写**邮箱**（即账号）、**密码**（8-16 位，含字母和数字）、**确认密码**，点击「发送验证码」，输入邮箱收到的验证码（1 分钟内有效）即可完成注册并自动登录。
3. 已注册账号再次尝试注册时，页面会提示「该账号已注册」，请切换到「登录」。
4. 此后 30 天内再次打开本页面无需登录；超过 30 天或更换设备后，用同一邮箱 + 密码重新登录即可找回全部进度。

## 三、运行环境要求

本应用为纯前端应用，注册、登录与进度同步依赖腾讯云开发（CloudBase）公网服务，因此**运行设备必须能访问公网**：

- 家庭宽带 / 手机流量 / 手机热点环境：直接可用。
- 公司等受限网络环境：可能被策略拦截，导致「无法连接云开发服务」。若出现该提示，请按本说明第六节处理。

## 四、数据存储说明

| 数据 | 存放位置 | 说明 |
|---|---|---|
| 学习打卡进度 | 云端 `user_progress` 集合 | 按账号隔离，打卡后自动上传；本地仅作缓存 |
| 用户资料（邮箱/昵称/首次注册时间/最近登录时间） | 云端 `users` 集合 | 注册、登录成功后自动写入 |
| 本机免登录时间戳 | 浏览器本地存储 | 仅用于 30 天免登录判断 |

## 五、云控制台配置（仅部署者需要）

首次在我机部署时，需在腾讯云开发控制台完成以下配置，之后所有用户无需再操作：

1. 在「数据库」中创建集合：`user_progress`、`users`，权限均选择「仅创建者可读写」。
2. 在「环境」→「登录授权」中开启「邮箱验证码登录」。
3. 将页面内 `CLOUDBASE_CFG` 的环境 ID 与区域替换为部署者自己的配置。
4. 将实际承载页面的域名加入 CloudBase Web 安全域名；未加入时，验证码、登录和进度同步可能被拦截。

## 六、常见问题

**问：打开显示「无法连接云开发服务」+「重试连接」按钮？**
答：点击「重试连接」；若提示「网络错误」，请检查网络连接（可尝试切换手机热点或家庭网络）后重试；若提示「邮箱或密码不正确」，请核对邮箱与密码。

**问：收不到邮箱验证码？**
答：请检查垃圾邮件箱；验证码 1 分钟内有效，可重新点击发送（60 秒后可重发一次）。

**问：换电脑后进度还在吗？**
答：在。用同一邮箱 + 密码登录，云端进度会自动同步到新设备。

**问：文件可以放在网盘/微信传给别人吗？**
答：可以，HTML 为单文件，任何设备双击即可使用，无需安装。
